[b]Precision Lab / 精密实验室[/b]
《深空当铺：可能是偷的》/ Probably Stolen 0.46D 的本地 mod。

[b]内容[/b]
- 精确取液器：1 µL 精度、双击设置量程、即时生效、三种方向模式
- 提纯机器：物理/化学/重金属/生物污染物，单行六格（含废料输出位与提纯上限）、说明便签
- 微生物培养机：营养果养菌、糖→有机废物、低糖休眠、活性实时显示
- 淀粉水解：淀粉 + 酸 40–60°C → 糖（酸为催化剂）
- 肾上腺素注射笔、纳洛酮（纳洛通）、避孕药、山奈德片、赛普那斯注射器生产线
- 简易止血带：韧棉织物 + 废金属/金属锭拖拽合成，开局可用，基础价值 150
- 药剂师：黑网解锁（1800），电话预约，次日第一个到店，冷却 3 天；出售随机原料盒、散装试剂瓶和随机品质成品药
- 拆分剂补充装：2 × 20 毫升，64 信用点，一次拆出 2 瓶满瓶拆分剂
- 《精密实验室配方手册》：游戏内书籍，6 页配方

[b]原料盒[/b]
3×2 格管制化学品瓶架外观（mod 自带透明底贴图，五条生产线液体颜色不同），非违禁品。

[b]提示修正[/b]
避孕药 / 山奈德片在普通生成、成型机压制、药剂师售卖时都使用游戏原版成分与纯度数据；赛普那斯注射器简介/风味与原版一致；药剂师夜报只保留冷却结束提示。

[b]反应速度[/b]
所有化学链每 tick 转化率 20%（原 2%），一批 20000 µL 约 15–25 秒完成。

[b]获取[/b]
黑网（游戏内手机）→「精密实验室」页签购买升级；之后杰克逊博士/退休化学家供应机器与原料盒；「药剂师」在 Referral 页签。

[b]安装[/b]
Steam 创意工坊订阅后，在游戏内 Mods 菜单启用并信任；需要游戏版本 0.46D。

[b]English[/b]
A local content mod for Probably Stolen 0.46D: precision extractor, purifier, cultivator, starch hydrolysis, adrenaline/naloxone/contraceptive/Sannai/Synaprest production lines, makeshift tourniquet, a phone-booked Apothecary (3-day cooldown, first customer next day, random kits + loose reagent bottles + random-quality medicines), 2-vial resolving-agent refill packs, and a 6-page in-game recipe book. Pills now use vanilla internal composition/purity; Synaprest description matches vanilla; apothecary night logs trimmed. Reactions run at 20% per tick.
